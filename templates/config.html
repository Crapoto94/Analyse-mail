Configuration Microsoft Graph API

Permet de récupérer directement les connexions, le journal d'audit et les règles de messagerie d'une boîte via l'API Microsoft Graph, en alternative à l'import manuel de CSV.

Paramétrage requis côté Azure (une seule fois) :
  1. Dans le portail Azure → Microsoft Entra ID → Inscriptions d'applications → Nouvelle inscription.
  2. Notez l'ID d'application (client) et l'ID de l'annuaire (locataire).
  3. Dans Certificats et secrets, créez un nouveau secret client et copiez sa valeur (visible une seule fois).
  4. Dans Autorisations API → Ajouter une autorisation → Microsoft Graph → Autorisations d'application (pas déléguées), ajoutez :
    • AuditLog.Read.All — connexions (sign-ins) et journal d'audit
    • MailboxSettings.Read — règles de messagerie (transfert, suppression...)
    • Mail.Read — messages envoyés (optionnel, seulement si vous cochez "+ messages envoyés")
    • User.Read.All ou Directory.Read.All — résolution des utilisateurs (recommandé)
  5. Cliquez sur Accorder un consentement admin pour le locataire (indispensable — sans ça les appels échouent en 403).
